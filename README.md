# rEvo ✓ Checklist

Checklist interattiva in italiano per il rebreather **rEvo III** (mCCR / hCCR-rMS), basata su:

- [Manuale rEvo III CE 2014 v0.5 (EN)](http://www.revo-rebreathers.com/wp-content/uploads/2016/02/Manual_rEvo_III_CE_2014_v05_ENG.pdf)
- [Checklist ufficiale rEvo v0.4 (EN)](http://www.revo-rebreathers.com/wp-content/uploads/2016/02/rEvo_checklist_v04_031013.pdf)

## Contenuto

- 🔧 **Montaggio** (build check) — con campi per analisi gas e millivolt delle celle
- 🔒 **Closed check** — con timer integrato per il test negativo (2 min)
- 🤿 **Pre-jump check** — con timer per il pre-breathe (5 min)
- 🌊 **In acqua** — promemoria (sempre in verde, volume minimo, cell check a 6 m…)
- 🔄 **Tra immersioni** / 🌙 **Fine giornata** / 🗓 **Manutenzione periodica**
- ℹ️ **Info** — limiti d'uso, SEMPRE/MAI, procedura Top Marker, drill, fonti

Funzioni: toggle mCCR / hCCR-rMS, contatore minuti scrubber (limite 160′), salvataggio
automatico in locale (localStorage), funziona **offline** (PWA installabile sul telefono:
"Aggiungi a schermata Home").

## ⚠ Avvertenza

Questa app è un promemoria personale: **non sostituisce l'addestramento con un'agenzia
riconosciuta né il manuale ufficiale rEvo**. Controlla sempre l'ultima versione delle
checklist sul [sito rEvo](https://www.revo-rebreathers.com/revo-downloads/).
